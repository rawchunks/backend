# Backend tests

Tests exercise Fastify routes, database queries and migrations, R2 transport, Valkey, generation/editing services, and the ACE-Step worker.

## Setup

From the repository root:

```sh
npm ci --prefix backend
npm ci --prefix backend/tests
python3 -m venv backend/tests/.venv
backend/tests/.venv/bin/pip install -r backend/tests/requirements-lock.txt
```

## Run

```sh
npm --prefix backend/tests run test:unit
npm --prefix backend/tests run test:gates
npm --prefix backend/tests run test:coverage
backend/tests/.venv/bin/python -m pytest backend/tests/python
npm --prefix backend run build
```

Unit tests replace network providers with deterministic adapters. Database integration tests execute production DDL and Drizzle queries in disposable PGlite databases. Python tests use model/tensor doubles; they do not require model weights or CUDA.

## Valkey integration

```sh
docker run --detach --rm --name rawchunks-tests-valkey --publish 127.0.0.1::6379 valkey/valkey:8.1-alpine
docker port rawchunks-tests-valkey
RAWCHUNKS_TEST_VALKEY_URI=redis://127.0.0.1:PORT npm --prefix backend/tests run test:stress
RAWCHUNKS_TEST_VALKEY_URI=redis://127.0.0.1:PORT backend/tests/.venv/bin/python -m pytest backend/tests/python
docker stop rawchunks-tests-valkey
```

Integration tests accept loopback URLs, use random namespaces, and remove only their own keys. They cover atomic admission, duplicates, concurrent updates, retention, leases and failed writes. The Python durable-worker tests require the same local server; tests skip when its URL is absent.

## Live checks

```sh
npm --prefix backend/tests run inspect:cluster
RAWCHUNKS_LIVE=1 npm --prefix backend/tests run test:live
```

Live probes load `backend/.env` and inspect the configured storage, database and self-hosted worker services. GPU result tests require evidence generated by the explicit runners under `live/`. Those runners have duplicate-submission guards and bounded workload configuration; do not delete run state to bypass them.

Sample tests read MP3 files from repository `fixtures/samples/`. Captured upstream worker fixtures include hashes and source provenance. Generated results, local environments and coverage output are excluded from Git.

Code coverage measures exercised source. Model doubles and decoder checks do not establish perceptual audio quality, cloned-voice fidelity, sustained GPU capacity, or recovery under actual hardware failure.
